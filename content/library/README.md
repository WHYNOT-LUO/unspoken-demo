# 平台参考资料放在这里

放在这里的 `.md` 或 `.txt` 文件，会和课程一起作为“全部：课程和参考资料”的回答依据，并在“我的资料”页面下方列出。英文版放在 `en/` 文件夹，文件名相同。

格式和课程文件相同，开头可以写：

```
---
title: 标题
summary: 一句话简介
order: 100
group: openstax     # 同一套资料用同一个 group，会在页面上归在一起，也可以在“回答依据”里单独选择
url: https://...    # 原文地址（可选），页面上会显示“阅读英文原文”
---
```

保存后刷新网页即可，不需要重启。新增一个 group 时，在 `public/js/i18n.js` 里加上 `lib.group.<名字>`（名称）和 `lib.credit.<名字>`（来源和许可说明）。
