# 课程引用核对记录 / Source log for lessons

每节课里的“书里怎么说 / 研究怎么说 / 国际指南怎么说 / 法律怎么说”提示框，以及文末的“参考资料”，都记录在这里：用了什么、是原话还是概括、出自哪里、怎么核对的。没有核对过的内容不写进课程。这个文件不会显示为课程。

Every source callout in the lessons is listed here: what is used, whether it is an exact quote or a summary, where it comes from, and how it was checked. Nothing goes into a lesson without a check. This file is not shown as a lesson.

核对日期 / Checked: 2026-11-12.

## 核对方法 / How sources were checked

- **书籍原话 / Book quotes:** 用 Open Library 的“书内搜索”（openlibrary.org/search/inside，检索 Internet Archive 扫描版全文）核对英文原句一字不差。这个接口给出的是扫描页序号，不是书上的印刷页码，所以课程里大多只写书名、年份和章节。卢森堡那一句的页码（第 3 版第 23 页）来自 Wikiquote，原句措辞已在 2015 年第 3 版的扫描全文里核对。
- **章节和步骤 / Chapters and steps:** 同样用书内搜索核对书中的目录或列表原文。
- **机构文件 / Organisation documents:** 直接阅读原文件（UNESCO 指南 PDF；CASEL 官网页面），页码为 PDF 印刷页码。
- **法律 / Laws:** 核对维基文库收录的官方文本（未成年人保护法 2024 年修正版；家庭教育促进法 2021 年）。条文号建议再到国家法律法规数据库 flk.npc.gov.cn 核对一次（本机无法访问政府网站）。
- **中文书名 / Chinese titles:** 豆瓣读书条目核对（《非暴力沟通》，马歇尔·卢森堡；《国际性教育技术指导纲要》，联合国教育、科学及文化组织，2018）。
- **翻译 / Translation:** 外文原句由本平台翻译，在中文课程里标注“本平台译”；英文课程使用原句。
